# Pierwsza wiadomość do Claude Code (do wklejenia)

1. Załóż strukturę repo zgodnie z `CLAUDE.md` i zbuduj stronę główną 1:1 z `docs/design-reference/strona-glowna.dc.html`: najpierw wszystkie sekcje statycznie, desktop i mobile.
2. Dodaj interakcje: slider ścieżek, slider bento na telefonie, akordeon opinii, formularz krokowy (wysyłka na razie atrapa).
3. Zrób workflow GitHub Pages, żeby strona była dostępna pod publicznym adresem.
4. Zatrzymaj się i wypisz, co wymaga mojej decyzji (menu mobilne, rozjazdy z projektem). Animacje dodamy w kolejnym kroku według moich wskazówek.

Treści nie zmieniaj, placeholdery `[…]` zostaw widoczne.
