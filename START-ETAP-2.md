# Wiadomość do Claude Code (do wklejenia)

Rozpakowałem w repo paczkę z podstronami. Przeczytaj `docs/ETAP-2-podstrony.md`, `docs/tresci-podstrony.md` i nowe pliki w `docs/design-reference/` (wspolpraca, startupy, o-mnie, kontakt). Potem:

1. Zbuduj cztery podstrony pod adresami `/wspolpraca/`, `/startupy/`, `/o-mnie/`, `/kontakt/`, 1:1 z projektem, desktop i mobile. Wspólne elementy (hero podstrony, FAQ, formularze, newsletter, stopka) zrób jako komponenty używane wszędzie.
2. Podepnij menu i linki między stronami, także ze strony głównej.
3. Dodaj animacje w tym samym stylu co na stronie głównej, a na O mnie rozdziały osi pojawiające się jeden po drugim.
4. Popraw reset odstępów według sekcji „Znany błąd” i powiedz mi, co się zmieniło na stronie głównej.
5. Dodaj `noindex` i `robots.txt` na czas podglądu i wypchnij na GitHub Pages.
6. Zatrzymaj się i wypisz, co wymaga mojej decyzji.

Treści nie zmieniaj, placeholdery `[…]` zostaw widoczne. WordPressa jeszcze nie ruszamy.
